# Configuration Reference

## Complete Option List

### Core

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `enabled` | `boolean` | `true` | Master switch |
| `inject` | `"off" \| "tree" \| "changed" \| "full"` | `"changed"` | Injection level |
| `injectStrategy` | `"first" \| "changed" \| "always"` | `"changed"` | When to inject full map |
| `summarizer` | `"outline" \| "model" \| "lsp"` | `"outline"` | Summarization strategy |
| `summaryModel` | `object` | - | Model for `model` summarizer |

### Injection

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `registerTool` | `boolean` | `true` | Register workspace_map tool |
| `refreshOnWrite` | `boolean` | `true` | Re-summarize on writes |
| `respectGitignore` | `boolean` | `true` | Honor `.gitignore` |
| `allowBroadRoot` | `boolean` | `false` | Allow home/fs roots |
| `debounceMs` | `number` | `50` | File change debounce |
| `treeTtlMs` | `number` | `10000` | Tree cache TTL |
| `treeDepth` | `number` | `3` | Tree depth |
| `maxTreeEntries` | `number` | `200` | Max tree entries |
| `maxInjectedChars` | `number` | `12000` | Max injection chars |
| `maxSummaries` | `number` | `50` | Max summaries per injection |

### Files

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `maxFiles` | `number` | `3000` | Max files to index |
| `maxFileBytes` | `number` | `500000` | Max file size |
| `maxFileBytesByExt` | `object` | `{}` | Per-extension limits |
| `warmupSummaries` | `number` | `20` | Startup summaries |

### Filtering

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `ignore` | `string[]` | `[]` | Extra ignore patterns |
| `ignoreExtra` | `string[]` | `[]` | Additional ignore patterns |
| `include` | `string[]` | `[]` | Force-include patterns |
| `debug` | `boolean` | `false` | Debug logging |

### Concurrency

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `walkConcurrency` | `number \| "auto"` | `"auto"` | Parallel walks |
| `summarizeConcurrency` | `number` | `4` | Parallel summaries |

### Summarization

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `summaryLength` | `"short"\|"medium"\|"long"` | `"medium"` | Model summary length |
| `autoTune` | `boolean` | `true` | Auto-detect project |
| `exportJsonl` | `boolean` | `false` | Enable JSONL export |
| `exportJsonlPath` | `string` | `".opencode/workspace-map.jsonl"` | JSONL path |

### LSP

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `lspTimeoutMs` | `number` | `10000` | LSP timeout |
| `lspMaxSymbols` | `number` | `500` | Max LSP symbols |

### Other

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `indexDotDirs` | `string[]` | `[".github", ...]` | Dot-dirs to index |
| `watchEnabled` | `boolean` | `true` | Enable watch mode |
| `includeReverseDeps` | `boolean` | `true` | Reverse deps index |
| `injectionFormat` | `string` | `"markdown"` | Output format |
| `followSymlinks` | `boolean` | `false` | Follow symlinks |
| `autoDetectGenerated` | `boolean` | `true` | Detect generated files |
| `generatedPatterns` | `string[]` | See below | Generated patterns |

### Watch Config

```json
"watch": {
  "debounceMs": 500,
  "batchChanges": true,
  "batchTimeoutMs": 100
}
```

### Cost Tracking

```json
"costTracking": {
  "enabled": false,
  "inputTokenPriceUsd": 0.0000015,
  "outputTokenPriceUsd": 0.000006,
  "logIntervalMs": 60000
}
```
