## Watch Mode Config

```json
"watch": {
  "debounceMs": 500,
  "batchChanges": true,
  "batchTimeoutMs": 100
}
```

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `debounceMs` | `number` | `500` | Debounce time before re-summarizing |
| `batchChanges` | `boolean` | `true` | Batch multiple changes |
| `batchTimeoutMs` | `number` | `100` | Max time to wait for batching |

## Cost Tracking Config

```json
"costTracking": {
  "enabled": false,
  "inputTokenPriceUsd": 0.0000015,
  "outputTokenPriceUsd": 0.000006,
  "logIntervalMs": 60000
}
```

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `enabled` | `boolean` | `false` | Enable cost tracking |
| `inputTokenPriceUsd` | `number` | `0.0000015` | $1.50 per 1M input tokens |
| `outputTokenPriceUsd` | `number` | `0.000006` | $6.00 per 1M output tokens |
| `logIntervalMs` | `number` | `60000` | Log interval in ms |
